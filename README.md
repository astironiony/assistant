# KnowledgeX

### The Open Knowledge Encyclopedia

KnowledgeX is an open knowledge project covering history,
science, technology, artificial intelligence, programming,
space and world culture.

## Explore

- History
- Technology
- Artificial Intelligence
- Science
- Space
- Programming
- World and Society

## Articles

Browse the [articles directory](articles/).

## Languages

The project currently publishes articles in Russian.
English content can be added as the project grows.
